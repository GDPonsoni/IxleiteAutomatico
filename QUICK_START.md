# ⚡ Guia Rápido

## 🚀 3 Passos para Começar

### 1. Instale Node.js
https://nodejs.org/ (versão LTS)

### 2. Execute
```bash
cd escala
npm start           # Ou rode o backend: cd backend && npm start
```

### 3. Acesse
```
http://localhost:3000
```

## 🆘 Problemas?

| Erro | Solução |
|------|---------|
| Porta em uso | Mude em `backend/server.js` |
| Sem módulos | `cd backend && npm install` |
| App não abre | Reinicie servidor (Ctrl+C + npm start) |
